**A. Create `src/components/history/SessionHistoryList.tsx`:**

A `'use client'` component that fetches and displays all past sessions.

1. State: `sessions` array, `isLoading` boolean, `error` string | null.

2. On mount (`useEffect`), fetch sessions from Supabase:
```typescript
const supabase = createClient();
const { data, error } = await supabase
  .from('sessions')
  .select('id, started_at, duration_s, total_meters, avg_split_ms, avg_watts, avg_stroke_rate, session_type')
  .order('started_at', { ascending: false });
```
No `.limit()` -- show all sessions. RLS handles user scoping.

3. Define a `SessionRow` interface for the query result:
```typescript
interface SessionRow {
  id: string;
  started_at: string;
  duration_s: number;
  total_meters: number;
  avg_split_ms: number | null;
  avg_watts: number | null;
  avg_stroke_rate: number | null;
  session_type: string | null;
}
```

4. Render a scrollable list of cards. Each card shows (per D-04, D-05):
   - Date: formatted from `started_at` as "Mon DD" (e.g., "Apr 08") using `new Date(started_at).toLocaleDateString('en-US', { month: 'short', day: 'numeric' })`
   - Session type (if set), in small gray text
   - Stats in a 3-column grid: Duration (MM:SS), Distance (X,XXXm), Split (M:SS/500m), Watts (NNNw), Rate (NN spm) -- laid out similar to SessionSummaryCard's StatBlock pattern but more compact

5. Card styling (consistent with dark theme and SessionSummaryCard):
   - Card: `bg-gray-900 border border-gray-800 rounded-2xl p-4`
   - Date header: `text-white text-base font-semibold`
   - Session type: `text-gray-500 text-xs uppercase tracking-wide`
   - Stats: inline flex row with dividers, `text-gray-300 text-sm` for values, `text-gray-500 text-xs` for labels

6. Format helpers (local to file, same logic as SessionSummaryCard):
   - `formatDuration(s: number): string` -- MM:SS
   - `formatSplit(ms: number | null): string` -- M:SS or "--:--"

7. Loading state: Skeleton cards (2-3 gray animated placeholder divs).

8. Empty state: Centered message "No sessions yet. Complete your first row to see it here." in gray-400 text.

9. Error state: "Could not load sessions. Pull down to try again." (or just show the error gracefully).
